# Security Policy

## Reporting a Vulnerability

Please do not report security vulnerabilities via public GitHub issues. 

Instead, please submit a report securely using GitHub's **Private Vulnerability Reporting** feature. You can find this by clicking on the **Security** tab at the top of this repository and selecting **Vulnerability reporting**.

We take device security seriously and will review your report as quickly as possible. Please include:
- A description of the vulnerability
- A proof of concept (PoC) or steps to reproduce
- The potential impact on connected hardware
